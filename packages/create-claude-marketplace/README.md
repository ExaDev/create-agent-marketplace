# create-claude-marketplace

Alias of [`create-agent-marketplace`](https://www.npmjs.com/package/create-agent-marketplace): the same initializer under a second name.

```sh
npm create claude-marketplace
```

It depends on `create-agent-marketplace` at an exact version and runs that package's CLI. Usage and flags are in the [repository README](https://github.com/ExaDev/create-agent-marketplace#readme).
