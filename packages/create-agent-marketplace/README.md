# create-agent-marketplace

Creates an agent marketplace (Claude Code plugins, agent skills or both) from the [ExaDev agent marketplace template](https://github.com/ExaDev/agent-marketplace-template).

```sh
npm create agent-marketplace
```

This package is generated from the template tag that matches its own version. Flags, the `--content` option and the rest of the documentation are in the [repository README](https://github.com/ExaDev/create-agent-marketplace#readme). `create-claude-marketplace` is an alias that runs the same CLI.
